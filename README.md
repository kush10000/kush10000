# Hi, I'm Kush Agarwal 👋

Software engineer moving from internal tooling into **forward-deployed / applied-AI engineering** — I like owning a problem end-to-end, from talking to the people who have it, through building and running the system in production.

### 🚀 What I'm building

**Sauda Manager** — embedded solo with a non-technical commodity broker to replace a paper-based deal register with production software. No spec — I extracted the data model (deals → commodities → deliveries) by observing how the business actually worked, then owned architecture, build, deployment, and now production operations myself.

- 📄 [Read the full case study →](https://kushagarwal-sauda-manager-case-study.netlify.app/)
- Stack: Next.js, TypeScript, PostgreSQL, Prisma, Google OAuth
- Client work — code is private, but the case study covers the architecture and the decisions behind it in depth

### 🧠 Currently learning

Hands-on with **AI agents** — tool-calling, agentic loops, and RAG fundamentals. Building small, real projects rather than just reading about them; repos going up here as they're done.

### 💼 Also working on

At **Equifax India**, contributing to the AWS → GCP migration of **InterConnect**, a real-time credit and fraud decisioning platform used by enterprise clients.
